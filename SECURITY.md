# Security Policy

## Supported Versions

Only the latest release version of **PingSystem** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **PingSystem**, please report it responsibly rather than opening a public issue.

### How to Report

1. Email your finding to the repository owner at `contact@sudhucodes.com` or create a **Private Security Advisory** on GitHub under the repository's Security tab.
2. Include details of the potential vulnerability, steps to reproduce, and any suggested fixes.

### Response Expectations

- **Acknowledgment**: Within 48 hours.
- **Assessment & Patch**: Security fixes will be prioritized and released as a patch release via GitHub Releases as soon as possible.
